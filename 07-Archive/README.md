# Archive

Finished, paused, or closed programs move here.

## When a program moves here

- All reports are resolved or closed, and no further testing is planned.
- The program is paused or retired on HackerOne.
- You decided to stop hunting this program (record the reason and date).

## How to archive

```bash
mv 00-Programs/<Name> 07-Archive/<Name>-YYYY-MM-DD
```

Then add one line below with the outcome.

## Rules

- Never delete an archived program folder. The scope, notes, and
  evidence are the record of what was tested and what was found.
- Never test an archived program without moving it back to
  `00-Programs/` and re-verifying its scope against the live HackerOne
  policy first.
