# Shared recon results

Results that span programs go here — for example a list of interesting
hosts found across several targets, or a shared technology fingerprint.

## What goes here

- Cross-program summaries (e.g. `2026-11-16-shared-hosts.txt`).
- Shared data that more than one program folder needs.

## What does NOT go here

- Per-program recon output — that lives in the program's own `recon/`
  folder (`00-Programs/<Name>/recon/`).
- Findings or evidence — those live in the program folder too.

## Naming convention

`YYYY-MM-DD-short-name.ext`
